# ControlDeck

Downloads for **ControlDeck**, an Android app that turns a phone or tablet into a control deck for volume,
brightness and media on the devices around it, over your local network.

- **Android:** get ControlDeck from Google Play.
- **Windows agent:** download `ControlDeck-Windows-v<version>.zip` from the
  [latest release](https://github.com/ogbar-dev/controldeck/releases/latest), unzip it and run
  `ControlDeck.Agent.exe`. Setup steps: <https://ogbar-dev.github.io/controldeck/>
